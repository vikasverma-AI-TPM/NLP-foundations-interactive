# NLP Foundations, Interactively Explained

A self-built interactive study guide covering One-Hot Encoding, Bag of Words, TF-IDF, and
Word2Vec — type your own sentence into any calculator and watch the math compute live,
right in the browser. No backend, no dependencies, a single self-contained HTML file.

**Live demo:** https://vikasverma-ai-tpm.github.io/NLP-foundations-interactive/

**Also deployed on:** https://nlp-foundations-interactive.netlify.app/

## What's inside

- **Encoding & Embedding foundations** — vectors, scalars, matrices, and the sparse-vs-learned distinction
- **One-Hot Encoding** — worked example + live calculator, with the one-hot vs. multi-hot terminology distinction
- **Bag of Words** — worked example + live calculator
- **TF-IDF** — full formula derivation + live calculator, matched against hand-verified worked examples
- **Word2Vec** — CBOW/Skip-gram, a neural network fundamentals section with a labeled diagram, negative sampling, the `xW = h` matrix-lookup explanation, and a roadmap of where this leads next (transformers, RAG)

Every topic page includes a short quiz with instant feedback.

## Tech stack

Vanilla HTML, CSS, and JavaScript — no frameworks, no build step, no external dependencies
beyond Google Fonts.
